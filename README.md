One funny single-line excuse a developer gives when code breaks in production, entered in the make.fun bounty "Make the AI Judge Laugh: Developer Excuses":

> Prod went down at 3am because the only server the code ever worked on was my laptop — and I just closed the lid.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (UTF-8, one line, 112 characters) and verifies the round-trip byte-for-byte.
